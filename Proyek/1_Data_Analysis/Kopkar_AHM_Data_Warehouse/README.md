# 🗄️ Case Study: Kopkar AHM Data Warehouse & Cooperative Analytics

## 📌 Ringkasan Proyek
- **Kategori:** Data Analysis & Data Warehouse
- **Organisasi:** Koperasi Karyawan PT Astra Honda Motor (Kopkar AHM)
- **Role:** Magang Data Warehouse Bisnis & IT Support
- **Periode:** Maret 2024 - Oktober 2024
- **Tools:** MySQL, Data Cleaning, Data Visualization, Spreadsheet, Inventory Analytics

---

## 🎯 Problem Statement
Pengelolaan catatan transaksi bulanan (pinjaman anggota, purchase order, dan stok persediaan) yang bervolume tinggi memerlukan rekonsiliasi data yang akurat guna mencegah selisih stok fisik gudang dan mempermudah pelaporan perkembangan koperasi kepada pengurus dan anggota.

---

## 🛠️ Metodologi & Langkah Kerja
1. **Data Extraction & Maintenance:** Menyusun dan memelihara basis data operasional bulanan pinjaman anggota, PO, dan stok barang.
2. **Data Cleaning & Reconciliation:** Mengontrol kondisi persediaan barang dan melakukan pembersihan data untuk meminimalisasi selisih stok gudang.
3. **Trend Analytics (2023 - 2024):** Menganalisis pertumbuhan koperasi dan menyajikan laporan visualisasi strategis kepada jajaran pengurus.
4. **QA & Testing:** Menguji fungsionalitas dan kualitas data aplikasi e-commerce Toko AHM versi 2 dan 3.

---

## 📁 Struktur Berkas Proyek:
- `datasets/`: Dataset sampel operasional koperasi.
- `sql_queries/`: Query SQL untuk rekonsiliasi stok dan laporan transaksi.
- `notebooks/`: Script analisis data persediaan.
- `documentation/`: Dokumentasi flow data warehouse dan hasil pengujian Toko AHM.
