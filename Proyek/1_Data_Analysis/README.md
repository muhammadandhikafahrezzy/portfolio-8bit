# 📊 Kategori 1: Data Analysis

Folder ini digunakan untuk menyimpan seluruh proyek analitik data teknis, data cleaning, exploratory data analysis (EDA), manipulasi dataset skala besar, dan optimasi query database.

---

## 📂 Subfolder yang Tersedia:
- **`Kopkar_AHM_Data_Warehouse/`**: Studi kasus pengelolaan data warehouse operasional, kontrol persediaan stok gudang, dan analisis data perkembangan koperasi 2023-2024 di Kopkar PT Astra Honda Motor.
- **`TEMPLATE_PROJECT_DATA_ANALYSIS/`**: Cetak biru template standar yang siap di-copy untuk memulai proyek data analysis baru.

---

## 🛠️ Standar Struktur Folder Proyek:
1. `datasets/`: Dataset CSV, Excel, atau JSON (mentah & yang sudah di-clean).
2. `sql_queries/`: File script query SQL (`.sql`) untuk ekstraksi, agregasi, filtering, dan joins.
3. `notebooks/` / `python_scripts/`: Jupyter Notebook (`.ipynb`) atau script Python (`.py`) untuk analisis statistik & visualisasi.
4. `reports/`: Ringkasan eksekutif, grafik insight, atau presentasi PDF temuan bisnis.
