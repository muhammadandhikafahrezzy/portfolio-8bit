# 📈 Kategori 2: Business Intelligence (BI) & Dashboard

Folder ini digunakan untuk menyimpan seluruh proyek visualisasi data, pelaporan eksekutif, pemodelan KPI bisnis, dan interactive dashboards menggunakan **Tableau, Looker Studio, Power BI**, maupun **Advanced Excel**.

---

## 📂 Subfolder yang Tersedia:
- **`Bitlabs_Executive_Sales_Dashboard/`**: Studi kasus dashboard performa penjualan dan segmentasi pelanggan (Bitlabs Academy Certification).
- **`TEMPLATE_PROJECT_BI/`**: Cetak biru template standar untuk proyek dashboard interaktif baru.

---

## 🛠️ Standar Struktur Folder Proyek:
1. `dashboards/`: File workbook Tableau (`.twbx`), link Looker Studio / Power BI (`.pbix`), atau file Excel interaktif.
2. `data_models/`: Skema relasi data (Star Schema / Snowflake Schema / ERD).
3. `kpi_definitions/`: Dokumentasi definisi metrik bisnis (CAC, LTV, Retention Rate, MoM Growth, Profit Margin, dll).
4. `sql_queries/`: Query SQL yang digunakan sebagai sumber data (data source connection).
