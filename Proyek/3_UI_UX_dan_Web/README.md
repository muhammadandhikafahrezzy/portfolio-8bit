# 💻 Kategori 3: UI/UX & Web Development

Folder ini digunakan untuk menyimpan seluruh proyek desain antarmuka pengguna (UI), riset pengalaman pengguna (UX), pemodelan alur data sistem (Data Flow Architecture), wireframing, dan prototipe aplikasi web.

---

## 📂 Subfolder yang Tersedia:
- **`Teknopolis_OSS_Licensing/`**: Studi kasus arsitektur informasi & desain sistem layanan perizinan pendidikan OSS.
- **`Unesa_Health_Care_Platform/`**: Studi kasus desain UI/UX platform kesehatan terpadu kampus.
- **`TEMPLATE_PROJECT_UI_UX_WEB/`**: Cetak biru template standar untuk proyek UI/UX atau Web baru.

---

## 🛠️ Standar Struktur Folder Proyek:
1. `figma_links/`: Link file desain Figma, design system, dan prototipe interaktif.
2. `user_research_and_flows/`: User Persona, User Journey Map, Information Architecture (IA), dan alur data pengguna.
3. `design_assets/` / `screenshots/`: Gambar aset ikon, wireframe low-fidelity, dan visual high-fidelity.
4. `prototypes/`: Kode prototipe web (Next.js / HTML CSS Tailwind).
