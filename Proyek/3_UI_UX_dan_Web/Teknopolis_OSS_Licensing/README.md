# 💻 Case Study: Teknopolis — Data Flow & UI/UX Perizinan OSS

## 📌 Ringkasan Proyek
- **Kategori:** UI/UX & Information Architecture
- **Konteks:** Sistem Layanan Perizinan Lembaga Pendidikan Terintegrasi Online Single Submission (OSS)
- **Role:** UI/UX Designer & Information Architect
- **Tools:** Figma, Canva, User Journey Mapping, Design System
- **Status:** Proyek Berkelanjutan (Agustus 2023 - Sekarang)

---

## 🎯 Problem Statement
Proses pengajuan izin operasional pendidikan seringkali memiliki alur data dokumen yang rumit, membutuhkan verifikasi berjenjang, dan minim visibilitas status real-time bagi pemohon izin.

---

## 💡 Solusi Desain
1. **Pemodelan Alur Data Regulasi:** Memetakan alur regulasi OSS ke dalam *User Journey Map* yang terstruktur.
2. **Dual-Direction Interactive Prototype:** Merancang prototipe antarmuka responsif untuk desktop dan mobile.
3. **Design System Konsisten:** Menyusun komponen UI yang ramah pengguna untuk meminimalkan beban kognitif saat pengisian formulir perizinan.

---

## 📁 Struktur Berkas Proyek:
- `figma_and_prototypes/`: Link dan file `.fig` desain antarmuka.
- `user_research_and_flows/`: Diagram Information Architecture (IA) dan flow pengajuan dokumen.
- `design_assets/`: Aset ikonografi, komponen button, dan mockup perangkat.
